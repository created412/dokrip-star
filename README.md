# 독립군의 별

1920년 만주. 봉오동에서 자유시까지, 한 소대를 데리고 가는 고등학교 한국사 수업용 브라우저 게임.

**`index.html` 파일 하나만 열면 됩니다.** 설치도, 서버도, 인터넷 연결도 필요 없습니다. 그림·음악·글이 전부 그 한 장 안에 들어 있습니다(약 2.3MB).

---

## 무엇을 하는 게임인가

교과서 서술을 읽히는 대신, **선택하게** 만듭니다. 그리고 그 선택이 사람 이름에 가서 붙습니다.

| 장면 | 하는 일 |
|---|---|
| 모닥불 | 기록 두 장을 읽고 **이름을 직접 적습니다.** 틀리면 그가 힌트를 한 단계씩 줍니다 |
| 주둔지 | 여섯 명을 눌러 이야기를 듣고, 셋이 가져온 결정에 답합니다. 한 명은 **곁에 둡니다** |
| 봉오동 | 세 박자. 전황판에 적의 위치·총성·인원·전투 기록이 쌓입니다 |
| 청산리 | 백운평과 어랑촌, 두 박자 |
| 간도 참변 | 불탄 마을 이름이 들어옵니다. 누군가의 고향입니다 |
| 밀산 | 같은 전투를 두고 숫자가 다른 기록 두 장을 **직접 판단**합니다 |
| 자유시 | 왜 국경을 넘었는가 → 두 개의 사령부 → 6월 28일 무장 해제 → 두 개의 사망자 수 |
| 증언 | 오늘 남아 있는 숫자, 이름이 남는 조건, 그리고 내 소대를 **공훈록 양식**에 넣어 보기 |

**어느 선택도 정답이 아닙니다.** 대가가 다를 뿐입니다. 6월 28일에는 사람이 죽지 않는 길이 아예 없습니다.

### 수업에서 쓰는 법

- 마지막 **명부** 화면의 「판단 기록 카드」를 복사하면 수행평가 자료가 됩니다. 따른 사람, 내린 결정, 사료 판단, 소대원 여섯의 최후가 전부 들어갑니다.
- 서술형 문항 세 개가 카드 끝에 붙어 있습니다.
- 한 판에 **40~50분** 걸립니다.

---

## 이 게임이 지키는 원칙

1. **실존 인물의 최후는 바꾸지 않습니다.** 홍범도·안무·김좌진·이회영·남자현·지청천 여섯의 마지막은 플레이어가 무엇을 하든 역사 그대로입니다.
2. **바뀌는 것은 지어낸 여섯입니다.** 박두칠·최봉근·오상길·정만수·김순덕·윤재호는 **가공 인물**입니다. 봉오동과 청산리에서 죽은 대다수는 오늘날 이름을 알 수 없기 때문에, 이름을 지어내는 방식으로만 그 자리를 채울 수 있었습니다.
3. **숫자를 하나로 못 박지 않습니다.** 봉오동 전과도, 간도 참변 피해도, 자유시 사망자도 기록마다 다릅니다. 게임은 서로 다른 기록을 나란히 보여 주고 학생에게 판단을 넘깁니다.
4. **교과서 밖 자료는 그렇게 표시합니다.** 모든 사료 카드에 「교과서 ○쪽」 또는 「교과서 밖 자료」 딱지가 붙습니다.

## 근거

- **교과서** — 동아출판 『고등학교 한국사2』 20 · 28 · 30~33쪽
- **사료** — 「국무원 포고」 제1호, 『독립신문』 제88호 전과 보도, 일본군 토벌 상황 보고, 고려 혁명 군정 의회 통고문, 사할린 의용대 성명, 『독립신문』 자유시 보도 (모두 현대어 요약)
- **집계** — 박은식 『한국독립운동지혈사』(간도 참변)

수치는 연구자마다 다릅니다. 게임 안에서도 그렇게 밝힙니다.

## 그림과 소리

- **실존 인물 사진** — 퍼블릭 도메인
- **장면·인물·선택지 그림** — 생성형 이미지로 그린 재현 일러스트. 화면마다 「재현 그림」 딱지가 붙습니다. 사진이 아닙니다.
- **배경음 다섯 곡** — `assets/bgm/` (낮 · 밤 · 전투 · 참변 · 명부). 게임 안에서는 40초 무이음 루프로 줄여 넣습니다.
- **효과음** — 합성(Web Audio). 총성·종·강물·종이·조작음.
- **본문 서체** — Song Myung, Nanum Myeongjo, IBM Plex Sans/Mono (Google Fonts). 폰트만 인터넷을 씁니다. 오프라인에서는 시스템 서체로 떨어지지만 게임은 그대로 돌아갑니다.

## 다시 굽기

```
python src/build.py
```

`src/` 의 조각들과 `assets/bundle/` 의 base64 묶음을 합쳐 `index.html` 을 다시 만듭니다.
인라인 스크립트의 SHA-256 을 계산해 CSP 에 박고, 배포용 `_headers` 도 같이 굽습니다. 파이썬 3만 있으면 됩니다.

```
index.html                완성본 — 이것만 배포하면 됩니다
privacy.html              개인정보처리방침
_headers                  보안 응답 헤더 (Cloudflare Pages·Netlify 형식, build.py 가 생성)
src/
  game.js                 게임 흐름 전부
  art.js                  하늘 그리기, 장면 그림 자리
  audio.js                배경음·효과음
  head.part  extra.css    틀과 스타일
  build.py                굽는 스크립트
assets/
  img/                    장면 17 + 선택지 19 + 얼굴 12 + 주둔지 2
  bgm/                    원본 mp3 다섯 곡
  bundle/                 build.py 가 먹는 base64 묶음
  portraits/              얼굴을 만들 때 쓴 원본
```

JS만 문법 검사하려면 `node --check src/check.js` (빌드할 때 같이 만들어집니다).
